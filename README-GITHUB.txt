# JeabJeab — Chick Theme 🐥✨

ไฟล์สำหรับ GitHub Pages ของ JeabDestiny.github.io

## ไฟล์
- index.html — หน้าเว็บ
- style.css — สี/ธีม/เอฟเฟกต์
- script.js — เอฟเฟกต์ 3D ตามเมาส์
- background.png — พื้นหลังธีมลูกเจี๊ยบ
- Jeablogo.png — โลโก้ JeabJeab

## วิธีติดตั้ง
1. เปิด repository `JeabDestiny/JeabDestiny.github.io`
2. เข้าแท็บ Code
3. กด Add file → Upload files
4. ลากไฟล์ทั้ง 5 ไฟล์จากโฟลเดอร์นี้ลงไป
5. ถ้ามีไฟล์ชื่อเดียวกันอยู่แล้ว ให้เลือกแทนที่ไฟล์เดิม
6. เลื่อนลง กด Commit changes
7. รอ GitHub Pages ประมาณไม่กี่วินาทีถึงไม่กี่นาที
8. เปิด https://jeabdestiny.github.io/

สำคัญ: `background.png` ต้องอยู่โฟลเดอร์เดียวกับ `index.html` และ `style.css`
